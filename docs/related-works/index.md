# Related works

This chapter discusses the projects and research that inspire and relate to imem.
First, it describes the main inspirations for imem and outlines the evolution of static memory management and static mutability control from Cyclone to Rust.
Next, it compares imem with existing approaches to static memory management and related problems in Scala.
Finally, it presents several recent and related works outside the Scala ecosystem and highlights their main differences from imem.
